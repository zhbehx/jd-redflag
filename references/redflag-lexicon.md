# 红旗词典

每条：**原文说法 → 真实含义 → 该问什么**。

## 一、加班与作息（高危）

| JD 原文 | 真实含义 | 面试怎么问 |
| --- | --- | --- |
| 抗压能力强 / 承受较大压力 | 会加班，且不打算给加班费 | 「最近三个月团队最晚一次几点走？」 |
| 狼性文化 / 狼性团队 | 结果压倒一切，过程保障很少 | 「完不成目标的人，通常怎么处理？」 |
| 弹性工作制 | 弹性上班，固定下班；或不写工时 | 「每天有固定的核心协作时间吗？几点到几点？」 |
| 能接受高强度工作 | 明确告诉你强度高 | 「平均每周实际工时大概多少？」 |
| 大小周 / 单休 / 6 天工作制 | 法定外的额外工作日 | 「大小周有额外的调休或补贴吗？」 |
| 快节奏 / 快速迭代 | 需求变更频繁，排期紧 | 「一个需求从提出到上线的典型周期是多久？」 |
| 随时响应 / 保持在线 | 下班后也要回消息 | 「非工作时间的响应预期是什么？」 |
| 996 / 007 / 奋斗者 | 明确的高强度信号 | 直接问工时与加班费 |

## 二、薪资陷阱（高危）

| JD 原文 | 真实含义 | 面试怎么问 |
| --- | --- | --- |
| 薪资面议 | 不想写，通常低于市场 | 「这个岗位的预算区间是多少？」（不给就问下一家） |
| 底薪 + 提成 / 提成上不封顶 | 底薪可能极低 | 「底薪具体多少？提成按什么口径算？」 |
| 薪资 5K–20K | 实际是 5K | 直接问「我这个级别对应哪个数」 |
| 绩效占比 40%+ | 一半工资看领导打分 | 「绩效的考核指标是什么？去年实际发放比例？」 |
| 试用期薪资 80% 以下 | 低于法定下限（不得低于 80% 且不低于最低工资） | 「试用期薪资是转正后的百分之多少？」 |
| 试用期不缴社保 | 违法 | 「社保从入职第几个月开始缴？」 |
| 期权 / 股权激励 | 常见于用未来抵现在 | 「行权价、成熟期、回购条款怎么定？」 |
| 年薪 30 万（含年终） | 月薪可能只有 1.5 万 | 「月薪和年终的比例是多少？年终去年实际发了吗？」 |

## 三、职责混乱（中危）

| JD 原文 | 真实含义 | 面试怎么问 |
| --- | --- | --- |
| 一人多岗 / 身兼数职 | 编制不够，一个人干几个人的活 | 「这个岗位现在几个人？我进来补哪块？」 |
| 其他领导交办的一切事务 | 边界无限 | 「日常工作中，临时事务大概占多少比例？」 |
| 配合老板处理日常事务 | 可能是私人助理性质 | 「这个岗位和老板的工作边界怎么划？」 |
| 岗位职责写得极宽（同时要会设计/开发/运营/销售） | 团队没定型，或想招便宜的全能工 | 「团队现在有哪些角色？缺的是哪一个？」 |
| 不限经验 / 学历不限（非销售岗） | 要么低薪，要么招不到人 | 「团队里和我同岗的人大概是什么背景？」 |

## 四、文化与话术（中危）

| JD 原文 | 真实含义 | 面试怎么问 |
| --- | --- | --- |
| 我们是一个大家庭 / 家文化 | 用情感替代制度与报酬 | 「团队的人员流动率大概多少？」 |
| 主人翁精神 / 把公司当自己家 | 要你自愿多干 | 「超出职责范围的工作，怎么算绩效？」 |
| 能者多劳 | 多劳但不多得 | 「多承担的部分，在晋升或薪酬上怎么体现？」 |
| 不要只看钱 / 要有情怀 | 钱给不到位 | 不用问，直接看薪资数字 |
| 有激情 / 有梦想 / 认同我们 | 常见于早期公司或高强度团队 | 「公司现在最难的阶段是什么？」 |
| 扁平化管理 | 可能没有明确汇报线与晋升机制 | 「晋升流程是什么样的？谁来评？」 |

## 五、承诺模糊（中危）

| JD 原文 | 真实含义 | 面试怎么问 |
| --- | --- | --- |
| 成长空间大 / 平台好 | 无法量化，通常是唯一优点 | 「过去一年，团队里有人晋升或涨薪吗？」 |
| 学习机会多 | 可能是没人带你 | 「新人前三个月有带教吗？」 |
| 未来上市 / 明年 IPO | 别把它算进你的收入 | 忽略，只看现金 |
| 行业前景好 | 只说明行业，不说明这家公司 | 「公司在行业里排第几？主要对手是谁？」 |

## 六、合规风险（高危，可直接判定）

| JD 原文 | 问题 | 应对 |
| --- | --- | --- |
| 缴纳押金 / 扣押证件 | 违法 | 直接不投 |
| 无薪试岗 / 试岗 3 天无薪 | 违法（提供劳动就应付酬） | 直接不投 |
| 入职不签劳动合同 | 违法（应自用工之日起一个月内签） | 问「什么时候签合同」 |
| 自费体检 / 自费培训后上岗 | 变相收费 | 问「费用谁承担」 |
| 离职需提前 3 个月 / 违约金 | 超过法定期限的约定无效 | 问「劳动合同里怎么约定的」 |

> 以上只是常见表象，**不构成法律意见**。涉及具体争议请咨询劳动仲裁或律师。

## 七、「太完美」也是红旗

有些 JD 完全没有上面这些词，反而更危险：

- 职责清晰、要求合理、薪资区间明确 —— 但公司成立不到半年、网上搜不到任何产品
- 「薪资 8–12K，双休，五险一金」写得很全 —— 但招聘岗位同时挂了 20 个，全公司只有 3 个人
- HR 头像是网图、JD 里公司名写成「某互联网公司」

**判断方法**：把 JD 里的信息与外部事实交叉验证（公司注册时间、产品是否存在、招聘岗位数量、有没有真实员工在社交平台提过）。脚本只能扫文本，这一层要人来做。

## 八、红旗密度比单条更重要

一个健康的 JD：要求具体、职责有边界、薪资有区间、福利写得清、不喊口号。

一个危险的 JD 通常是：**口号多 + 要求宽 + 薪资模糊 + 责任无限**。

看到这四条同时出现，哪怕每条单独看都不算严重，也建议谨慎。
