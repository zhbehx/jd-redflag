# 案例：一份「什么坑都有」的 JD

## 原始 JD

```
我们是一个充满激情的大家庭，团队氛围扁平化管理，能者多劳。

岗位职责：
1. 负责公司品牌在小红书、抖音等平台的日常内容策划与发布；
2. 独立完成短视频脚本撰写、剪辑与发布，能接受出镜；
3. 负责社群运营、用户增长、活动策划与执行；
4. 配合市场部完成各类推广物料的设计与制作；
5. 负责电商店铺的日常运营、客服与售后处理；
6. 完成领导交办的其他一切事务。

任职要求：
1. 抗压能力强，能接受高强度工作，适应快速迭代的节奏；
2. 有主人翁精神，把公司当成自己的家；
3. 一人多岗，身兼数职，多面手优先；
4. 不要只看钱，我们看重的是情怀与成长空间；
5. 期待未来上市的伙伴加入，期权激励丰厚；
6. 学历不限，经验不限，只要你有激情。

薪资面议，底薪加提成，上不封顶。试用期工资打八折。
```

## 脚本输出（实测）

```
$ python scripts/scan_jd.py jd.txt --explain

风险分：100/100    高危：建议只当练手，去的话逐条问清
命中：高危 5 · 中危 9 · 提醒 4   （JD 267 个汉字）

【文化与话术】7 条
  [中危] 「大家庭」       含义：用情感替代制度与报酬
       问法：团队的人员流动率大概多少？
  [提醒] 「扁平化管理」    含义：可能没有明确汇报线与晋升机制
       问法：晋升流程是什么样的？谁来评？
  [中危] 「能者多劳」      含义：多劳但不多得
       问法：多承担的部分在晋升或薪酬上怎么体现？
  [中危] 「主人翁精神」    含义：要你自愿多干
       问法：超出职责的工作怎么算绩效？
  [高危] 「不要只看钱」    含义：钱给不到位
       问法：（不用问，直接看薪资数字）
  [提醒] 「有激情」       含义：常见于早期公司或高强度团队

【职责混乱】4 条
  [中危] 「一人多岗」「身兼数职」  含义：编制不够，一个人干几个人的活
       问法：这个岗位现在几个人？我进来补哪块？
  [提醒] 「学历不限」「经验不限」  含义：低薪信号，或招不到人

【加班与作息】3 条
  [高危] 「抗压能力强」    含义：会加班，且大概率没有加班费
       问法：最近三个月，团队最晚一次几点走？
  [高危] 「高强度」       含义：明确告诉你强度高
  [中危] 「快速迭代」      含义：需求变更频繁，排期紧

【薪资陷阱】3 条
  [高危] 「薪资面议」      含义：不想写，通常低于市场
       问法：这个岗位的预算区间是多少？
  [高危] 「试用期工资打八折」 含义：可能低于法定下限
       问法：试用期薪资是转正后的百分之多少？
  [中危] 「期权」         含义：用未来抵现在
       问法：行权价、成熟期、回购条款怎么定？

【承诺模糊】1 条
  [中危] 「未来上市」      含义：不要算进你的收入

【JD 没写的（比写了的更值得警惕）】
  - 薪资区间：没写薪资区间：大概率低于市场，或想看你报多少
  - 五险一金：没写社保：入职前必须问清什么时候开始缴
  - 工作时间：没写工时：默认按最差的假设（大小周或更差）
  - 团队规模：没写团队规模：可能是新设岗，或这个岗只有你一个人
```

## 对照：一份正常 JD

```
岗位名称：增长产品经理（P6）
岗位职责：3 条（增长、协作、指标口径）
任职要求：3 条（经验、技能、跨部门推动）
薪资：25–35K · 14 薪
工作时间：双休，9:30–18:30
福利：五险一金按实际工资缴纳，补充医疗，年度体检
团队：直属上级为增长负责人，团队 8 人
```

```
$ python scripts/scan_jd.py jd_normal.txt

风险分：0/100    相对正常：正常投，注意下面「没写的东西」
命中：高危 0 · 中危 0 · 提醒 0   （JD 180 个汉字）
```

**100 分 vs 0 分**，同一套规则跑出来的。这就是可比较的意义。

## 这份 JD 真正在找什么人

把六条要求连起来读，画像很清楚：

> 一个**不用培训、能一个人干完内容 + 短视频 + 社群 + 电商 + 客服 + 物料**的人，工资按最低给，用「期权 + 情怀 + 未来上市」抵现。

对应到岗位名称，它其实不是「内容运营」，是**「小公司的第 3 个员工」**。

这类岗位不是绝对不能去——如果你要的是「短时间内什么都摸一遍」，它确实能给。但你要知道你在换什么：**用低于市场 30–50% 的现金，换一段什么都干过的经历**。

## 面试必问的 3 个问题

按危害排序，挑最要命的三条问（问多了会显得你在挑刺）：

### 1. 关于「抗压能力强」

❌ 别问：「你们加班多吗？」——一定答「还好」

✅ 要问：
> 「这个岗位上一任做的人是多久之前离开的？大概是因为什么？」

这句话能同时问出：岗位稳定性、真实强度、离职原因是否和加班有关。如果对方说「这个岗位是新设的」，那就问：
> 「那现在这些活是谁在做？」

### 2. 关于「薪资面议 + 底薪加提成」

❌ 别问：「无责底薪是多少？」——容易一开始就对立

✅ 要问：
> 「这个岗位的预算区间大概是多少？我想确认一下我们是不是在同一个范围里。」

拿到区间后再问：
> 「底薪和提成的比例大概是几比几？提成按什么口径算——流水、毛利还是回款？」

### 3. 关于「一人多岗 + 其他一切事务」

❌ 别问：「是不是一个人干好几个人的活？」

✅ 要问：
> 「这个岗位的六块职责里，如果我只能优先做好两块，您最希望是哪两块？」

这问法很关键：**它逼对方说出真实的优先级**。如果对方回答「都很重要」，那答案已经出来了。

## 这个案例说明了什么

1. **红旗密度比单条重要。** 单看「扁平化管理」不算问题，但它和「大家庭 + 能者多劳 + 抗压 + 一人多岗 + 薪资面议」一起出现，画像就非常清楚。
2. **没写的东西更致命。** 这份 JD 一个字的薪资区间都没有，一个字没提社保，一个字没写工时。
3. **脚本给的是问法，不是结论。** 它不会告诉你「别去」，它告诉你「去之前问这三句」。
